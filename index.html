PETier API 文档

通过 PETier API 查询玩家排名、游戏模式与 Tier 数据。公开接口无需登录即可测试；添加、修改和删除数据等操作需要管理员身份验证。

接口基础地址
https://petierapi.ccwu.ccHTTPS

下方接口路径均以此地址为基础。

快速开始

GET/api/players

获取一页玩家资料及其 Tier 信息。

curl "https://petierapi.ccwu.cc/api/players?page=1&limit=20"
本页面会调用现有后端接口，不会创建或修改服务器路由。只有后端请求成功后，数据变更才会生效。

可用接口

方法接口路径用途权限
GET/api/players获取及筛选玩家公开
GET/api/players/:id获取单个玩家公开
GET/api/modes获取游戏模式与等级列表公开
POST/api/auth/login管理员登录账号密码
POST/api/players添加玩家管理员
PUT/api/players/:id修改玩家管理员
DELETE/api/players/:id删除玩家管理员
POST/api/auth/change-password修改密码管理员
安全与权限

身份验证

管理员登录使用现有的 POST /api/auth/login 接口。登录成功后，服务器会返回 JWT Token；执行写入操作时，需要在请求中携带该 Token。

POST/api/auth/login
{
  "username": "your-admin-username",
  "password": "your-admin-password"
}

成功响应示例：

{ "token": "JWT_TOKEN" }

携带身份令牌

Authorization: Bearer YOUR_JWT_TOKEN

当前后端签发的 Token 有效期为七天。退出登录会清除本页面保存的 Token，但无法让已经复制到其他地方的 Token 立即失效。

请勿向他人提供管理员密码或 JWT Token。正式使用前，请确认 Cloudflare Worker 已设置安全的 JWT_SECRET，而不是使用代码中的默认密钥。
接口说明

获取玩家列表

GET /api/players

返回分页数据，包含 total、page、limit 和 players 字段。

查询参数

参数类型说明
searchstring按玩家名称进行模糊搜索
regionstring按地区筛选
modestring游戏模式代码，例如 sword
tierstring需同时提供 mode 才能按等级筛选
sortid/name/tier排序字段
orderasc/desc排序方向
pageinteger页码，默认为 1
limitinteger每页数量，范围 1–200，默认 50
GET /api/players?search=North&mode=sword&tier=HT1&page=1&limit=50
接口说明

获取单个玩家

GET /api/players/:id

根据数字 ID 获取玩家资料及各游戏模式的 Tier 信息。

Success: { "player": { "id": 1, "name": "...", "tiers": {} } }
接口说明

游戏模式与等级

GET /api/modes

按配置的顺序返回游戏模式列表和 Tier 等级列表。

Expected structure: { "modes": [...], "tiers": [...] }
管理员接口

添加玩家

POST /api/players Admin token required

创建玩家。玩家名称不能重复；还可以填写颜色、备注、地区及各模式的 Tier。

Sign in first. The interactive form is available in Admin Editor.
{
  "name": "ExamplePlayer",
  "color": "#FFFFFF",
  "note": "",
  "region": "",
  "tiers": {
    "sword": { "tier": "LT3", "peak": "LT3" }
  }
}
管理员接口

修改玩家

PUT /api/players/:id Admin token required

修改玩家名称、颜色、备注、地区及提交的 Tier 记录。若某个资料字段未提交，后端会在支持的情况下保留原值。

巅峰等级现在可以自由设置：可升级、可降级、可清空。未提交的模式不会改动，提交空值则清除该模式的巅峰。
{
  "name": "North_Ling",
  "color": "#FFFFFF",
  "note": "",
  "region": "",
  "tiers": {
    "sword": { "tier": "HT1", "peak": "HT1" },
    "axe": { "tier": "LT2", "peak": "LT2" }
  }
}
管理员接口

删除玩家

DELETE /api/players/:id Admin token required

删除指定玩家。根据数据库表结构，该玩家关联的 Tier 记录也会级联删除。

删除操作不可轻易恢复。发送请求前，请再次确认玩家 ID。
管理员接口

修改密码

POST /api/auth/change-password Admin token required

根据当前后端规则，需要提供旧密码；新密码长度至少为六位。

{
  "oldPassword": "current-password",
  "newPassword": "new-password"
}
